# Report

Final Master's Thesis report for **Breathe Barcelona**, developed as part of the Master's Degree in Data Science, Big Data & Business Analytics at Universidad Complutense de Madrid (UCM).

The report presents the complete project methodology, from the integration of heterogeneous open urban data to temporal and geospatial modelling, model interpretation, and the development of the Breathe Barcelona interactive dashboard.

## Document

**`Susana_Fugarolas_Alvarez-Ude_Breathe_Barcelona_TFM_report.pdf`**
